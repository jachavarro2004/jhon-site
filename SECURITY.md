# Security policy

This repository is Jhon's landing page: static HTML, CSS, a little JavaScript
and media files, served by GitHub Pages. Thank you for reporting a security
problem in it privately.

## Supported versions

Only the page as served from the default branch
(https://jachavarro2004.github.io/jhon-site/) gets security fixes.

## Reporting a vulnerability

Please do not open a public issue, discussion or pull request for a
vulnerability.

- **Preferred:** open a private report from the repository's Security tab
  (Report a vulnerability). It reaches the maintainer only.
- **If you cannot use GitHub:** write to jhon87195@outlook.com.

Include what you can:

- what an attacker can do through the page, and what they need first;
- the steps that show it, with the browser you used;
- the file or the section of the page involved.

## What to expect

- An acknowledgement within 7 days.
- An assessment, and a fix or a mitigation plan, as soon as the problem is
  understood. You are kept informed along the way.
- Credit in the fix's commit, unless you ask not to be named.

## Scope

In scope: this repository's files (the page, its script and styles, its
assets) and what they do in a browser, such as a script or a link that leads
somewhere it should not.

Out of scope: Jhon itself (the `jhon` binary, its guards, the installer and
the releases); report those through
[jhon-agent's security policy](https://github.com/jachavarro2004/jhon-agent/security/policy).
Problems in GitHub Pages, a browser or another upstream project go to them.
